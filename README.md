# Заявки автосервиса

Учебная библиотека модели предметной области и консольная демонстрация на Java 21.

## Возможности
- Клиенты и сотрудники через наследование от `Person`.
- Автомобиль с VIN как ключом равенства (`equals` / `hashCode`).
- Заявки, работы, расчёт стоимости через `PriceCalculable`.
- Статусы заявки как конечный автомат с проверкой переходов.
- Собственное исключение `InvalidTransitionException` и `DuplicateVinException`.
- Поиск по VIN, список заявок в работе на дату, поиск просроченных заявок.
- Журнал переходов, длительность ремонта и среднее время по типу работ.
- Консольная демонстрация с 10 клиентами, 10 автомобилями и 10 заявками.

## Требования
- JDK 21
- Maven 3.9+

## Запуск
```bash
mvn clean test
mvn package
java -cp target/classes ru.autoservice.Main
```

JUnit 5 тестирует VIN, equals/hashCode, расчёт стоимости, переходы статусов, исключения и граничные случаи.

## Модель
`Person` — абстрактный базовый класс; `Client` и `Employee` — наследники.
`PriceCalculable` — интерфейс расчёта стоимости.
`Vin`, `RepairWork` и `StatusHistory` — records для значений.
`OrderStatus` — перечисление и машина состояний.
`AutoService` — сервис поиска и управления заявками.
